    Median asking rent by building type

    Boston’s housing stock is mixed in a way you won’t find anywhere else. Triple-deckers (Multi-Family) sit alongside brownstones, condos, and big apartment buildings — and the per-bedroom price tells very different stories. Active listings only, dedupe by address + unit + bedrooms.

    How we calculate this

    We classify each listing by the building_type field set by the listing agent. Active listings only (is_on_market = true), rents $500–$20,000, deduped by address + unit + bedroom count keeping the most recent. Cells with fewer than 15 active listings are suppressed.
